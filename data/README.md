# Dữ liệu

- Dữ liệu cước/vùng dùng trong demo: `backend/data/*.json`.
- Dữ liệu cảm biến dạng số: [hardware/calibration/data.xlsx](../hardware/calibration/data.xlsx).
- Ảnh thu thập bưu gửi, ảnh/label training và các tài liệu knowledge base được giữ trong bộ dữ liệu gốc ở ngoài repository; không sao chép vào bản public.

Danh mục vùng và cước là snapshot đi kèm đồ án, chưa đối chiếu chính sách hiện hành. `data/raw/` là vị trí local đã được Git bỏ qua nếu cần lưu dữ liệu riêng khi tiếp tục nghiên cứu.
