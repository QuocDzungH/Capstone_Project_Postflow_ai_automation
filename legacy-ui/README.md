# Giao diện thử nghiệm cũ

Giữ `demo.html`, `final.html` và `final3.html` để tham khảo quá trình xây dựng giao diện. Các bản `final1.html`, `final2.html` có nội dung trùng bản được giữ nên không sao chép thêm.

Giao diện được kiểm tra trong portfolio là `index.html` ở root, chạy qua FastAPI. Các tệp ở đây chưa được nối thành route của API hoặc kiểm thử như một ứng dụng độc lập.
